# Interface# (I#)

**Interface is the Application.**

Interface# is a strictly-structured, AOT-compiled programming language designed to eliminate spaghetti code at the compiler level.

## Philosophy
- **Explicit over implicit** — every dependency is declared in the `@Special` block.
- **Interface as contract** — a `.isa` file is both project and package.
- **Compiler-enforced discipline** — naming conventions, block ordering, and IO permissions are checked at compile time.
